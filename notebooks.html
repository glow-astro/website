Using them

A release is pinned to the paper it came with, so cite the version DOI where there is one: it names the exact deposit the numbers came from, which a link to a repository cannot do once the repository moves on. The code in these releases is not maintained and is not the place to start a new analysis. For that, use GLoW, which is where the methods behind most of this work live in a form meant to be built on.

Only what is actually public is listed here. A repository still private, or a deposition still a draft, is absent rather than promised; the release policy says when it appears.
