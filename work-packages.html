The work packages run in parallel. WP1 supplies the lens models that WP2 searches for and WP3 interprets; the loop closes by informing back the necessary theoretical developments.

This page outlines the plan: what the project is set to do and how. For the physics behind it — what these phenomena are and what they can measure — see the science topics, which each task links to.
